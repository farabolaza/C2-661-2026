Repaso sobre funciones y listas

Podemos usar el problema de Fibonacci de la práctica para repasar las funciones y algunas propiedades de las listas en python. Ya que los valores de \(f_n\) se calculan una y otra vez, quizás podríamos guardar éstos mismos en una lista. En python una lista es cualquier cosa encerrada entre corchetes.

lista = []

arriba vemos una lista vacía

lista = [2,3]

Lista con dos elementos numéricos

lista = [2.0,2,'boca','river']

Lista con elementos mixtos

lista[2]

nos devuelve el elemento que ocula la posición 2 (recordar que los índices empiezan en cero)

lista[2] = 'velez'

asigna el dato ingresado en la posición 2 de la lista.

podemos agregar un valor al final de una lista usando

lista.append('mi nuevo valor')

Funciones

Las definimos tal como en matemática

def f(x):
  y=2*x
  return y

la palabra def es reservada para definir funciones. Luego del nombre, en el ejemplo es f entre paréntesis van los argumentos. Luego, en el bloque central las instrucciones. La palabra return hace explicita la ejecución de la función y “devuelve” lo que se ponga allí. De todas formas, las funciones pueden imprimir en consola respuestas o valores sin necesidad de que devuelvan un resultado mediante return.

def f(x):
  y=2*x
  print(y)

la diferencia radica en que al imprimir, el resultado sólo esta visible en pantalla y no podemos volver a usar ese dato para otro cálculo o proceso. por ejemplo, si uno quisiera Graficar la función f debería poder tener los valores de entrada y salida como pares ordenados y eso sólo podríamos lograrlo mediante el uso de return. Más adelante profundizaremos.

Para Fibonacci

def fibo(n):
  serie = [0,1]
  ratio = ["-",1]
  if n <= 2:
    print(serie[0:n]) # imprime desde las posiciones 0 a la n de la lista serie
    print(ratio[0:n]) # imprime desde las posiciones 0 a la n de la lista ratio
  else:

    for i in range(1,n):
      serie.append(serie[i]+serie[i-1])
      ratio.append(serie[i+1]/serie[i])

    print(serie)
    print(ratio)

Se puede definir un método recurrente (que se llama a sí mismo dentro de su definición) para calcular la sucesión de Fibonacci. Lo pueden googlear, pero es didácticamente bastante oscuro, por lo que no lo recomiendo como material de enseñanza.

Lo que si se puede hacer, es la versión mas sencilla, que también es un poco críptica pero más clara, que sería algo así:

def fib(n):
    f_n = 0  # posición n
    fn_1 = 1  # posición n+1

1    for k in range(n):
2        fn_2 = fn_1+ f_n
3        f_n = fn_1
4        fn_1 = fn_2

        # para n=1
        # fn_2 = 1+1
        # f_n = 1
        # f_n1 =2

        # para n=2
        # fn_2 = 2+1 =3
        # f_n = 2
        #fn_1 = 3

        # para n=3
        # fn_2 = 3+2= 5
        # fn = 3
        # fn_1 = 3

    return f_n

for i in range(8):
  print(fib(i))

recorro de 0 a n calculando los valores
2

3

4
