Arduino 03

Extraer datos de Arduino 01

Objetivos de esta actividad

Necesidad de la conexión

Como hemos visto podemos visualizar la información de aquello que tengamos conectado en Arduino a través del monitor serie. Para hacer de esa información algo útil, debemos extraerla de allí. Podemos copiar y pegar, útil y rápido para algunos casos, aunque demasiado engorroso y propenso a errores para muchas otras situaciones.

En esta clase vamos a tener un primer acercamiento a extraer datos de Arduino simplemente “copiando y pegando”

Preparación en Arduino

Ejemplo con el HCSR-04

const int TRIG = 9, ECHO = 10; // Definir donde están los pines

void setup() {
  Serial.begin(115200);
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  delay(2000);  // Espera para estabilizar
  Serial.println("tiempo_ms,distancia_cm");
}

void loop() {
  // Medición de distancia
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  
  long duracion = pulseIn(ECHO, HIGH);
  float distancia = duracion * 0.034 / 2; //distancia  en cm
  
  // Exportación CSV
  Serial.print(millis());
  Serial.print(",");
  Serial.println(distancia, 1);  // 1 decimal
  
  delay(20);  // ~50 muestras/segundo (opcional)
}

const int TRIG_PIN = 9;
const int ECHO_PIN = 10;

void setup() {
  Serial.begin(9600);
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
}

void loop() {
  static unsigned long lastTime = 0;
  if (millis() - lastTime >= 30) {  // Muestreo cada 30ms
    
    // Disparo del pulso ultrasónico
    digitalWrite(TRIG_PIN, LOW);
    delayMicroseconds(2);
    digitalWrite(TRIG_PIN, HIGH);
    delayMicroseconds(10);
    digitalWrite(TRIG_PIN, LOW);
    
    // Medición del eco
    long duration = pulseIn(ECHO_PIN, HIGH);
    float distance = duration * 0.034 / 2;  // Cálculo de distancia en cm
    
    Serial.print(millis() / 1000.0, 3);  // Tiempo en segundos
    Serial.print(",");
    Serial.println(distance, 1);          // Distancia en cm
    
    lastTime = millis();
  }
}

Actividad

Vamos a usar el sensor HCSR-04 en un diseño experimental.

Montaje experimental

El objeto será tratar de medir el período de un péndulo simple. Para ello necesitamos:

  • Base universal
  • Montaje para hilo (morsa, gancho u otro accesorio del soporte)
  • Hilo
  • Masa “puntual” (esfera metálica)

Con estos elementos procederán a montar tal como si fueran a medir el período del péndulo de forma manual.

Planteo de adquisición de datos

¿Cómo harían para medir el período de un péndulo usando el sensor HCSR-04?

  1. ¿Qué datos vamos a usar para medir el período?
  2. ¿Cómo vamos a obtenerolos?
  3. ¿De qué manera podemos conseguir el período a partir de nuestros datos?

Una vez tomadas estas decisiones deberán montar el Arduino e iniciar su funcionamiento, verificando que efectivamente está midiendo aquello que intentan medir.

Extracción de datos

Cuando hayan tenido éxito en la parte anterior, podrán copiar y pegar los datos a un archivo de texto, cambiar su extensión a “.csv” y abrirlo en una planilla de cálculo.

Análisis de los datos

  1. ¿Qué fórmulas pueden usar para obtener el período a partir los datos
  2. ¿Es necesario hacer ajustes en el código de arduino para facilitar el análisis?

Si fuera necesario, vuelvan a correr el experimento habiendo ajustado el código o la ubicación de los materiales para obtener mejores datos.

Como meddida poco rigurosa pero necesaria, hagan una medición con cronómetro de unos cuantos períodos y comparen sus resultados con los obtenidos meidante Arduino/Planilla de Cálculo.
