Arduino 01

Introducción

Ojbetivos de la clase

La placa Arduino

La placa Arduino permite la interacción entre el mundo físico y el digital mediante el uso de componentes electrónicos y sensores. No se trata de una única placa sino una familia de placas de software y hardware libre. De ésta familia utilizaremos la más usual, Arduino Uno (y sus clones).

Los entornos de trabajo

Arduino IDE

El software arduino IDE es el software que permite escribir el código y subirlo a la placa para su ejecución

Tinkercad

El sitio Tinkercad ofrece la posibilidad de escribir en el lenguaje Arduino y simular componente a componente un circuito entero, lo que es de mucha utilidad para practicar cuando se está comenzando o testeando un nuevo diseño.

El lenguaje de programación de Arduino

Arduino tiene su propio lenguaje de programación que está inspirado y replica en parte al lenguaje C++. Nosotros nos centraremos las estructuras de control más sencillas (que ya vimos para python) que resultan ser ligeramente diferentes en Arduino en cuanto a su sintaxis pero que hacen efectivamente lo mismo que sus parientes Pythonicas. Por su parte, el funcionamiento de la placa requiere de ciertas estructuras que se encuentran siempre presentes y son escenciales para su funcionamiento.

Entradas y salidas

La placa consta de entradas analógicas (allí donde conectaremos la mayoría de los sensores y componentes electrónicos) y pines digitales. Los pines digitales pueden actuar tanto como entrada o como salida. Para especificarlo se usa la función pinMode(PIN,OUTPUT/INPUT). La salida que estos pines pueden dar es binaria: 0V o 5V para poder emular una salida analógica algunos pines cuentan con un proceso llamado PWM (modulación por ancho de pulso) que en pocas palabras lo que hace es emitir como salida trenes de pulsos de una duración muy breve a intervalos regulares. El promedio del tiempo que se encuentre en 0V o 5V emulará un voltaje real. Por ejemplo, si en el ciclo entero está la mitad de tiempo en 0V y la otra mitad en 5V el voltaje “emulado” será de 2,5V. Para identificar que pines pueden hacer esto, se los señala con el acento circunflejo, virgüilla, más conocido como el “cosito de la eñe”, es decir “~”.

Conexión de un led

Un diodo LED es un tipo especial de diodo. Los diodos son componentes electrónicos en cuyos detalles se profundizará en la materia electrónica. Por el momento sólo necesitamos saber que el diodo tiene polaridad: si lo conectamos al revés, no funciona. Tiene un lado positivo o ánodo, y uno negativo, o cátodo. Simuladores de circuitos

Algo que nos puede prevenir dolores de cabeza, además de dormir ocho horas y alimentarse bien, es usar algún simulador de circuitos para prototipar nuestro trabajo. Especialmente quienes no sean expertos en electrónica, sacarán provecho de poder previsualizar su trabajo y observar el comportamiento esperado de conexiones que quienes saben de la materia pueden imaginar con facilidad, pero a nosotros simples mortales que quizás no fuimos a una escuela ténica nos parece magia negra.

Existen opciones en línea, comerciales, de código cerrado y de código abierto.

  • Tinkercad: Muy popular, cerrado. Perteneciente a la empresa Autodesk
  • Velxio: También popular, sin necesidad de registrarse y de código abierto (basado en Wokwi)
  • Wokwi: En línea y de código abierto (licencia MIT). Con fuciones de pago
  • SimulIDE: De escritorio y de código abierto (GPLv3) que permite prototipado offline
  • AVR8js: Es el motor base de Wokwi
  • UNOArduSim: Enfocado en depuración de código para Arduino Uno
  • ArduinoSimulator: proyecto web en JavaScript

Este año probaremos trabajar con Velxio ya que no requiere de iniciar sesión ni tener cuenta para comenzar a tarbajar, (aunquel es conviene hacerse una cuenta) reduciendo la fricción de los primeros pasos.

La conexión real

Abrimos arduino IDE, que es el software que interactúa y permite cargar código a la placa.

  1. Conectar la placa
  2. Instalar drivers (si fuera necesario)
  3. Conectar el cable usb a la placa y a la pc
  4. En Arduino IDE, ir a Heramientas > Placa y elegir el modelo conectado (Arduino Uno).
  5. Luego, ir a Herramientas > Puertos y seleccionar el puerto en el que la placa está conectada.

En windows a veces es necseario chequear que la placa fue correctamente reconocida,

  • Ir a Heramientas > Administrador de dispositivos y verificar que la placa haya sido reconocida.

Las placas “clones” a veces pueden dar algún problema en esta primera conexión. internet es una buena fuente de información sobre cómo solucionarlo, pero en general, los pasos pueden incluir un reseteo de la placa, reinstalar drivers, etc.

Copien y peguen el codigo de abajo en el IDE (o tómenlo del menú de ejemplos)

/*
  Blink

  Turns an LED on for one second, then off for one second, repeatedly.

  Most Arduinos have an on-board LED you can control. On the UNO, MEGA and ZERO
  it is attached to digital pin 13, on MKR1000 on pin 6. LED_BUILTIN is set to
  the correct LED pin independent of which board is used.
  If you want to know what pin the on-board LED is connected to on your Arduino
  model, check the Technical Specs of your board at:
  https://docs.arduino.cc/hardware/

  modified 8 May 2014
  by Scott Fitzgerald
  modified 2 Sep 2016
  by Arturo Guadalupi
  modified 8 Sep 2016
  by Colby Newman

  This example code is in the public domain.

  https://docs.arduino.cc/built-in-examples/basics/Blink/
*/

// the setup function runs once when you press reset or power the board
void setup() {
  // initialize digital pin LED_BUILTIN as an output.
  pinMode(LED_BUILTIN, OUTPUT);
}

// the loop function runs over and over again forever
void loop() {
  digitalWrite(LED_BUILTIN, HIGH);  // change state of the LED by setting the pin to the HIGH voltage level
  delay(1000);                      // wait for a second
  digitalWrite(LED_BUILTIN, LOW);   // change state of the LED by setting the pin to the LOW voltage level
  delay(1000);                      // wait for a second
}

Luego le darán a compilar/verifica (tilde) y subir (flecha hacia la derecha). Si todo funciona bien, verán un mensaje de éxito en la parte inferior del IDE.

Cambiando el código

Pueden probar este código con la conexión anterior (atención usar pin PWM):

int pinPWM = 10

void setup(){
    pinMode(pinPWM,OUTPUT);
}
void loop(){
    for(i=0;i<=255;i++){
    analogWrite(pinPWM,i);
    delay(1000);
    }
}

¿Qué se podría cambiar en el código para que la iluminación progresiva sea “ida y vuelta”, es decir, de apagado a prendido y de prendido a apagado.
