Condicionales y bucles

Condicional if

En python las secuencias se encierran en bloques indentados, con tabulaciones

Sintaxis (ver los espacios):

if condicion:
    hace_algo
elif condicion:
    hace_esta_otra_cosa
else:
    haga_esto_otro # se suele usar para errores
                 # luego de una lista de opciones

La conversión implícita de los valores a bool() se hace si la condición a evaluar no es booleana en sí misma:

n = 2

if n:
    print("n no es cero o no es null")

if n is None:
    print("n es None")

if n is not str:
    print("n no es una cadena de texto")

Podemos añadir bifurcaciones usando elif

x = 20
y = 21

if y > x:
    print('y > x')
elif y < x:
    print('y < x')

La palabra reservada and implica que ambas condiciones deben ser verdaderas

if x==20 and y==21:
    print('True')
else:
    print('False')

La palabra reservada or implica que al menos una condición debe ser verdadera

if x==20 or y==100:
    print('True')
else:
    print('False')

Bucle for

El bucle for es quizás la construcción más habitual en python. Su sintaxis es

for elemento in secuencia:
    haga_esto

En un ejemplo:

for i in [0, 1, 2, 3, 4, 5]:
    print(i)

Usando la función range() (que devuelve los enteros del conjunto)

for i in range(2,5):
    print(i)

Usando una lista y la función enumerate() para devolver el elemento y su posición en la lista

list_a = ['P','S','Y','C','H']

for index, value in enumerate(list_a):
    print(index, value)

Recorriendo los elementos de una cadena de texto uno a no

cadena_de_texto = "Python facilita la ciencia"
for c in cadena_de_texto:
    print(c)

Estructura try-except

Se puede atrapar o “atajar” errores usando esta estructura. Cada vez que el programa de como resultado un error (un dato mal ingresado o no válido) podremos especificar que hacer. Se puede indicar incluso una respuesta diferente para errores de distinto tipo.


try:
    acción_a_intentar
except:
    que_hacer_si_ocurre_un_error

Contenedores

Los datos en Python se almacenan en aluna de estas cuato opciones - list (lista) - dict (diccionario) - set (conjunto) - tuple (tupla)

Listas

Una lista es una arreglo mutable. Lo que quiere decir que podemos redefinir y alterar sus valores - Cada valor en la lista es un elemento o item - Los elementos pueden ser cualquier objeto - Las listas pueden contener objetos de diferente tipo

  • Una lista vaciía se define como [] o como list()
l = [1,2,3]
  • Los elementos de una lista estan indizados o indexados (contando desde 0)
l[0]
  • Los elemnentos pueden ser listas en sí mismas
lista_anidada = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
  • Las listas pueden ser “rebanadas”
l[inicio:fin:orientación]

Diccionarios

  • Un diccionario (dict) es un mapeo entre un conjunto de índices (keys) y otro de valores (values)
  • Cada objeto de un diccionario es un par índice-valor (key-value)
  • Las claves pueden ser cualquier tipo de dato
  • Los diccionarios no tienen un orden prestablecido

Los diccionarios se escrbien entre llaves

eng2sp = {}
eng2sp['one'] = 'uno' # la clave 'one' tiene como valor 'uno'
print(eng2sp)
eng2sp = {'one': 'uno', 'two': 'dos', 'three': 'tres'}
print(eng2sp)

Las claves y sus valores se pueden acceder a través de los métodos .keys() y .values()

print(eng2sp.keys())
print(eng2sp.values())

Funciones

Una función es una secuencia de instrucciones que ejecuta un cálculo o acción al invocarla por su nombre y, opcionalmente al proveerle los argumentos necesarios. Para crear una función, usamos la palabbra reservarda def y a continuación el nombre de la función, segudia de los argumentos entre paréntesis

Ejemplo

def poner_en_mayuscula(texto):
    """
    Esta función pone en mayúsculas el
    texto que se ingresa
    """
    return (texto.upper())
  • Entre paréntesis están los argumentos.
  • Se puede decir que una función “toma” un argumento y “devuelve” un resultado.
  • Al resultado se lo suele llamar valor de retorno.
  • No es necesario que una función retorne un valor

La primera línea de la función se la llama encabezado (header) y a las restantes el cuerpo (body).

El ebcabezado va encerrado entre comillas y el cuerpo tiene que estar indentado. La indentación común es de 4 espacios y un error común es que el software que se usa confunda tabulaciones con indentación. Apretar la tecla tab, si el software está bien configurado, debería hacer los 4 espacios y no una tabulación. Esto parece una aclaración contradictoria y poco relevante, pero como se dijo más arriba, es una fuente común de errores en la ejecución de código: si hay tabulaciones en donde deberían estar los 4 espacios de la indentación, el código no se ejecuta.

El cuerpo de una función termina cuando se vuelve al nivel anterior de indentación.

Para consultar más acerca de funciones, pueden visitar la ayuda de Python oficial

Funciones para recibir entradas del usuario

Una función para permitir al usuario interactuar con el código ingresando valores es la función input() cuyo funcionamiento se ejemplifica a continuación:

user_input = input("Ingrese algo: ")
print(f"Usted ha ingresado: {user_input}")

Hay que tener en cuenta que la función input entiende todo lo que ingresemos a ella como si fuera texto, por lo que si deseamos recibir valores numéricos debemos convertir lo que recibamos. Por ejemplo:

1price = float(input("Ingrese el precio: "))
print(f"El precio es {price}")

2age = int(input("Ingrese su edad: "))
print(f"Usted tiene {age} años")

2
Se convierte a un número entero int
