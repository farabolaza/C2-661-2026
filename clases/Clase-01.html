Fracciones

Bueno, las fracciones no son representaciones “típicas” en los lenguajes de programación, y en python, debemos usar los módulos específicos para operar con ellas. Más información acá. Veremos más adelante como trabjar con fracciones.

  • string
  • Integer
  • Float
  • Boolean
  • None
# String
c = 'hello'
print(type(c))
# Integer
a = 1
print(type(a))
# Float
b = 1.0
print(type(b))
# Boolean
d = True
print(type(d))
# None
e = None
print(type(e))

Operadores de cadenas de texto

Los operadores matemáticos son diferentes en las cadenas de texto, por ejemplo el sigo + se usa para unir cadenas

Repeticiones: Se usa *n para repetir una cadena n veces

# Asignar y combinar cadenas
a = 'Hello'
b = 'World'
print(a + ' ' + b)
# f-strings: reemplazarvalores de variables en cadenas
firstname = 'Beto'
print(f'Me llamo {firstname}')
# Combininar f-strings
firstname = 'Beto'
lastname = 'Velez'

print(f'My name is {firstname} {lastname}')
# Repetir una cadena
print(str(a)*5)
# Repetir un cadena con espacios
print(str(a+' ')*5)

Operadores lógicos

Hacen una comparación y devuelven un booleano (verdadero o falso)

x == y # x es igual a y
x != y # x no es igual a y
x > y # x es mayor que y
x < y # x es menor que y
x >= y # x es mayor o igual que y
x <= y # x es menor o igual que y
  • En cadenas de texto
  • En datos numéricos
a = 'hola'
b = 'que tal'
c = 'Hola'
print('a==b: ' + str(a==b))
print('a==c: ' + str(a==c))
print('a!=b: ' + str(a!=b))
print()
d = 5
e = 8
print('d < e: ' + str(d < e))
print('d >= e: ' + str(d >= e))

Ejercicios

  1. Crear una variable de tipo numérica
  2. Asignar a la variable un número entero, por ejemplo “1” y ejecutar la función type sobre ella.
  3. Asignar a la variable un número con decimales ejemplo “3.5” y ejecutar la función type sobre ella.
  4. Crear dos variables, a una asignarle un valor numérico entero y a otra uno con lugares decimales, pero que coincidan. Por ejemplo “5” y “5.0” compararlos usando el operador lógico de igualdad. ¿Qué se obtiene?
